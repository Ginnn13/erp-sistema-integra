# Sistema Integra

Prototipo web responsive del ERP **Sistema de Gestión de Transporte y Encomiendas con IA (J-I-K)**. La aplicación convierte los 16 flujos IFML del capítulo 11 en interfaces navegables para escritorio y móvil.

## Módulos

- Gestión de Encomiendas y Clientes (J): 8 flujos.
- Gestión de Transporte y Rutas (K): 4 flujos.
- Seguimiento, Entrega y Analítica (I): 4 flujos.

## Ejecución local

No requiere instalación ni compilación. Puede abrirse `index.html` directamente o servirse con cualquier servidor HTTP estático.

```powershell
npx serve .
```

## Tecnologías

- HTML5 semántico
- CSS3 responsive
- JavaScript ES6

Los datos y operaciones del prototipo son simulados con fines académicos.
